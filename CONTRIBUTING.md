# Contributing to react-rotary-fab

Thank you for your interest in contributing to `react-rotary-fab`! We welcome bug reports, feature suggestions, documentation enhancements, and pull requests.

## Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/react-rotary-fab.git
   cd react-rotary-fab
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the demo app**:
   ```bash
   npm run dev
   ```

4. **Run tests**:
   ```bash
   npm run test
   ```

5. **Type check**:
   ```bash
   npm run typecheck
   ```

6. **Build library**:
   ```bash
   npm run build
   ```

## Pull Request Guidelines

- Ensure all existing and new unit tests pass (`npm run test`).
- Ensure TypeScript compiles without errors (`npm run typecheck`).
- Add tests for any new features or bug fixes.
- Update documentation in `README.md` if public APIs or props change.
- Follow conventional commits format (e.g., `feat:`, `fix:`, `docs:`, `chore:`).

## Code of Conduct

Please be respectful and constructive in all issues and pull requests.
